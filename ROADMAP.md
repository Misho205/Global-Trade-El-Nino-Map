# Roadmap

A prioritized plan, not a delivery commitment.

## Before public release

- [ ] Complete the security audit and independent verification of fixes.
- [ ] Review third-party license files and bundled asset provenance.
- [ ] Enable private vulnerability reporting and publish a verified contact.
- [ ] Validate real D1 migrations, hosted Cron and persisted readback.
- [ ] Measure Cloudflare CPU, memory, redirects, requests and D1 quotas.
- [ ] Test mobile/desktop accessibility, translation and error states in a browser.
- [ ] Finish visible branding and publish a tagged release with notes.

## Reliability and coverage

- [ ] Refresh and retain climate/water subfeeds independently.
- [ ] Monitor publication/observation age and collector failures.
- [ ] Evaluate versioned data retention and history storage.
- [ ] Automate reproducible AlphaEarth exports with validated provenance.
- [ ] Improve historical treaty membership and country-code coverage.
- [ ] Evaluate licensed AIS/carrier feeds and regional ocean/hydrology models.
- [ ] Improve translation across all pages and multilingual documentation.

New integrations need implementation, licensing and coverage validation; adding
an API key alone does not provide them.
